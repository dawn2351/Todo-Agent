# 小明智能体 · 中文待办清单

用中文对话记录、查看和处理待办。侧边任务面板随对话更新，也可以直接勾选任务。任务保存在本机，刷新页面或重启服务后仍能查询。

## 本地运行

需要 **Node.js 24.12 或更高版本**及 npm。在终端执行以下命令。

+`sh
git clone https://github.com/dawn2351/Todo-Agent.git
cd Todo-Agent
npm ci
npm run dev
+`

打开 <http://127.0.0.1:3000>。常用指令无需 API 密钥。任务首次写入时会创建 `data/tasks.json`，刷新会清空当前对话，任务清单仍可查询。

### 启用 DeepSeek

在项目根目录将 `.env.example` 复制为 `.env`。PowerShell 使用 `Copy-Item .env.example .env`，macOS 或 Linux 使用 `cp .env.example .env`。在 `.env` 中填写自己的 `DEEPSEEK_API_KEY`，默认模型为 `deepseek-flash`，然后重启服务。`.env` 和本地任务数据均由 Git 忽略。

启用后，小明优先使用模型理解最近几轮对话。目标明确时，服务端校验并执行任务操作，小明根据实际结果组织回复。目标不明确时，小明会追问。模型暂不可用时，常用指令回退到本地解析。若任务已写入，回复生成失败时会直接显示原始结果。

## 已实现功能

| 功能           | 使用方式                                                             |
| -------------- | -------------------------------------------------------------------- |
| 管理待办       | 通过聊天创建、查看、标记完成、恢复待办和删除，刷新或重启后可继续查看 |
| 任务面板       | 查看待办、已完成及到期数量，直接勾选完成或取消勾选恢复               |
| 截止日期       | 查询今天到期及逾期待办，日期按北京时间计算                           |
| 优先级和工作量 | 添加或修改高、中、低优先级及小、中、大工作量                         |
| 子任务         | 给主任务添加一层子任务并独立管理，删除主任务时子任务移入主清单       |
| 搜索和处理建议 | 按关键词找任务，或按逾期、今天到期和优先级获得最多三项建议           |
| 同名任务处理   | 列出候选任务的完成状态和短编号，由用户指定目标                       |
| 模型对话       | 理解自然表达及跨轮指代，也能直接回答、给出建议或追问                 |

## 设计取舍、边界与不足

- **设计取舍** 模型理解对话，服务端校验并执行任务操作，回复保留实际结果。本地 JSON 降低部署成本，模型暂不可用时仍可使用常用指令。
- **边界情况** 同名任务按短编号确认，无效日期会被拒绝，重复标记完成会保留现有状态。删除主任务时，子任务移到主清单。
- **当前不足** 面向单机使用，每轮处理一项操作，子任务限一层。到期通知和跨设备同步仍待实现，刷新页面会清空当前对话。

## 验收方法

在浏览器中依次发送以下消息。建议在没有同名测试任务的清单中验收。

| 发送             | 预期结果                                   |
| ---------------- | ------------------------------------------ |
| 帮我记一下买牛奶 | 新增待办「买牛奶」                         |
| 再记一条取快递   | 新增待办「取快递」                         |
| 我有哪些任务？   | 两条任务都显示为待办                       |
| 牛奶买好了       | 「买牛奶」标记为已完成，「取快递」仍为待办 |
| 取快递这条删掉吧 | 删除「取快递」                             |
| 再给我看看清单   | 这两条测试任务中只剩已完成的「买牛奶」     |

刷新页面并再次说「看看清单」，确认「买牛奶」仍显示为已完成。停止并重新运行 `npm run dev` 后重复查询，可以验证本地持久化。也可以访问 <http://127.0.0.1:3000/api/tasks> 查看原始数据。

扩展功能可以用下面的对话验证。

- 发送「添加待办：准备面试，今天到期，优先级高，工作量大」，再问「今天有哪些任务到期？」。
- 发送 `给「准备面试」添加子任务「练自我介绍」`，再查询「查看准备面试的子任务」。
- 发送「搜索 面试」「有哪些逾期任务？」或「今天先做什么？」。在任务面板勾选一项，再切到「已完成」取消勾选，核对状态变化。
- 配置 DeepSeek 后，先说「有件事怕我忘，把橙色铅笔带到排练室，替我留个底好吗？」，再说「刚才那件事我已经搞定啦」。小明会理解第二句话指向第一句话创建的任务。
